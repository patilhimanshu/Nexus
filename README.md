# Nexus

Nexus is an AI-powered workspace intelligence platform built with Python.

It understands your projects, organizes your files, and connects the right AI to the right task — so you never lose context again.

---

## What Nexus Does

### File Organization
- Watches your Downloads folder in real time
- Classifies files by extension automatically
- Moves them to the right folders without you thinking about it

### Project Intelligence
- Pick any project folder and Nexus reads it
- Finds the most important files — README, entry points, dependencies
- Understands your project structure deeply

### AI-Powered Q&A
- Ask anything about your project in plain English
- Nexus detects your intent and routes the right context to the right AI
- Streams responses word by word like ChatGPT

### Smart Context Routing
- Casual question → fun personality, no project context
- General coding question → professional response
- Project question → full codebase context sent to AI
